## About This Directory

Problems are stored in `problems/<difficulty>/<number>_<name>/` and linked here using junction points (Windows) or symbolic links (Linux/Mac). This allows you to:

1. **Browse by difficulty** in `problems/easy/`, `problems/medium/`, `problems/hard/`
2. **Browse by topic** in `topics/arrays/`, `topics/strings/`, etc.

The same problem appears in both locations without duplicating files.

## Common Array Patterns

1. **Two Pointers**
   - Used for sorted arrays
   - Finding pairs/triplets
   - Example: Two Sum (sorted version)

2. **Sliding Window**
   - Subarray problems
   - Maximum/minimum in window
   - Example: Maximum Sum Subarray

3. **Hash Map**
   - O(1) lookup
   - Finding complements
   - Example: Two Sum

4. **Prefix Sum**
   - Range sum queries
   - Subarray sum problems

5. **Kadane's Algorithm**
   - Maximum subarray sum
   - Dynamic programming on arrays

## Tips for Array Problems

- Always consider edge cases: empty array, single element
- Think about time/space trade-offs
- Consider if sorting helps
- Look for patterns: two pointers, sliding window, etc.
